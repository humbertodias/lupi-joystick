# lupi-joystick

Controller test cassette for [Lupi](https://github.com/lupi-org-br) - a Super Famicom pad drawn with primitives.
Based on [controller-test-cartridge-1990-snes](https://downloads.khinsider.com/game-soundtracks/album/controller-test-cartridge-1990-snes)

- Play in the browser: [humbertodias.github.io/lupi-joystick](https://humbertodias.github.io/lupi-joystick/)
- Cassette: [lupi-joystick.lupi](https://github.com/humbertodias/lupi-joystick/releases/latest/download/lupi-joystick.lupi)

### How to run

```shell
lupinho lupi-joystick.lupi
```

### Mapping

| SNES  | Constant  | Keyboard |
|-------|-----------|----------|
| Left  | `LEFT`    | A |
| Right | `RIGHT`   | D |
| Up    | `UP`      | W |
| Down  | `DOWN`    | S |
| B     | `BTN_Z`   | K |
| X     | `BTN_X`   | J |
| Y     | `BTN_F`   | G |
| A     | `BTN_G`   | H |
| L     | `BTN_Q`   | L |
| R     | `BTN_E`   | M |

Reference https://lupi.api.br/docs/system.html
